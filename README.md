# MC Entertainment & Event Website

## 소개

MC Entertainment & Event Website는 행사 및 엔터테인먼트 서비스를 소개하고 고객 문의를 받을 수 있는 웹사이트입니다.

이 프로젝트는 바이브 코딩 플랫폼(Base44)과 ChatGPT를 활용하여 개발되었으며, 사용자에게 직관적인 인터페이스와 다양한 행사 정보를 제공합니다.

## 주요 기능

* 행사 및 엔터테인먼트 서비스 소개
* 회사 정보 및 포트폴리오 제공
* 고객 문의 및 상담 신청 기능
* 반응형 웹 디자인 지원
* 모바일 및 데스크톱 환경 최적화

## 사용 방법

### 설치

```bash
git clone https://github.com/[YOUR_GITHUB_ID]/[REPOSITORY_NAME].git
cd [REPOSITORY_NAME]
npm install
```

### 실행

```bash
npm run dev
```

### 빌드

```bash
npm run build
```

## 프로젝트 목적

본 프로젝트는 엔터테인먼트 및 행사 서비스 정보를 효과적으로 제공하고, 고객과의 소통을 지원하기 위해 제작되었습니다.

또한 바이브 코딩(Base44)과 생성형 AI(ChatGPT)를 활용한 웹 서비스 개발 경험을 바탕으로 구축된 프로젝트입니다.
