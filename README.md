# MAKE ONE ENTERTAINMENT

## 소개

MAKE ONE ENTERTAINMENT는 행사 진행, MC 섭외 및 엔터테인먼트 서비스를 소개하기 위한 공식 웹사이트입니다.

본 프로젝트는 Base44 기반 바이브 코딩과 ChatGPT를 활용하여 개발되었으며 사용자에게 직관적인 정보 제공과 문의 기능을 제공합니다.

---

## 주요 기능

- 회사 소개
- 행사 서비스 안내
- MC 섭외 안내
- 고객 문의 기능
- 모바일 반응형 지원
